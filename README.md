## Autonomous UAV Landing System
### Khattat Abdallahi  

#Research Goal

Autonomous precision landing for fixed-wing UAVs in GPS-denied 
environments using visual-inertial odometry.

## Current Status

 Active Research — March 2026

## Technology Stack

- Python 3
- Gazebo 11
- ArduPilot SITL
- OpenCV
- ANSYS Fluent (CFD)
- MATLAB
