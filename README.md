 # Autonomous UAV Landing System

## Research Goal
Develop an autonomous precision landing system for fixed-wing UAVs 
operating in GPS-denied environments using visual-inertial odometry.

## Tools
- ROS Noetic
- Python 3
- Gazebo 11
- ArduPilot SITL
- OpenCV
- MATLAB
